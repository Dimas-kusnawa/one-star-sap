A program that writes one line to `/output/entry.txt` (178 characters, inside the 280-character cap): a one-star review written by a houseplant about its human owner — three years in the same pot with no drainage, roots drowned and then called "needy", while the pothos next door got a name and this plant got a sticky note that says "plant?".

## Run it

```sh
python3 main.py
```
